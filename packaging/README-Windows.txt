Oligarchy Tanks
===============

HOW TO PLAY

1. Unzip this folder somewhere you can keep it (for example, your Desktop).
   Keep all the files together: the .exe needs the DLLs and the folders next
   to it.

2. Double-click "oligarchy-tanks.exe".

3. Windows SmartScreen will warn the first time, because this build is not
   signed with a paid certificate. Click "More information", then
   "Run anyway". After that, a normal double-click works.

CONTROLS

   Player 1   W A S D to move, Space to fire
   Player 2   arrow keys to move, Enter to fire
   P pause    R back to the menu    M mute    Q quit

A DualSense or Xbox pad works over USB: press START to join, left stick or
d-pad to move, Square / X (or L2 / R2) to fire, SHARE / SELECT for the menu.

If the pad does nothing, make sure "SDL2.dll" is in this same folder as the
.exe — it is the gamepad reader. The game itself never uses the network.
